# Figure selection record

The 18 October 2026 scan covered 6,210 PNG/JPEG/PDF/SVG candidates across the source project, including history and the verified current production output. The final resolved inventory retains 192 scientific images: 7 current main figures, 10 current supporting figures and 175 historical figures. The packaged SI has no embedded figures.

`selection_decisions.json` records every source decision. `../figure_exclusions.csv` links scientific exclusions to retained figures. `../figure_inventory.json` records captions, original source placements, byte identities, decoded dimensions/pixel identities and related original analysis scripts where available. Historical scripts are provenance references, not validated regeneration registrations.

Selection compared source contracts/captions, variable sets, cohorts, transformations and panels. All retained raster images decoded successfully. Contact-sheet review covered all candidates selected before the final overlap merges; full-size checks resolved the supplied six event heatmaps and ambiguous cohorts. PDF-only single plots were compared using page text/cohort counts and their exported counterparts. Manuscript/report/figure-book containers and page renders are accounted for as containers or QA artifacts; individual scientific exports are retained separately. Browser icons, dummy/style previews and figure components are not independent scientific results.

The current 17 figures take precedence over their earlier presentations. Historical plots with different populations, wavelengths, raw/month/year-month adjustments, backscatter diagnostics, measurement checks or geometry conventions remain distinct. The historical 550 nm optical composite with B1005/P58/D8/mixed4 is retained once; the 550 nm stored-zero plot is covered by the all-wavelength composite. Current main mass figures cover the earlier mass-only composite. Retained hourly and monthly views cover redundant combined versions.

Historical images keep their original scientific conventions. Older sphere-surface distributions must not be interpreted as the current projected-area distributions, and historical backscatter analyses are not current backscatter validation. The final cross-check retained both before/after-backscatter-removal mass-selection cohorts and the six-panel sphere-surface composite. Its number/surface/volume row exports are covered by that composite. Additional figures are preserved as original images; only the registered current 17 are regenerated by this launcher.

`pdf_pages.json` maps all 560 pages of 21 scientific figure books to their same-run individual exports and canonical figures. Of these, 509 have identical decompressed vector drawing streams; 51 match full extracted text and page geometry from the same run. The geometry comparison allows 0.0001 point for PDF decimal serialization. No page is unresolved. Manuscripts and response documents remain document containers, with their scientific exports separately inventoried.

The additive ZIP contains 175 canonical images and 204 companion PDF/SVG exports from the same source run/stem. All 379 assets were extracted and byte-compared to their sources. Both original ZIP hashes remained unchanged. Historical provenance records available original source context, caption/run contracts and input/derived-table identities; unavailable original pipelines are explicitly identified.
