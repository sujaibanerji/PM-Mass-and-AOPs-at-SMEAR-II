# Historical launcher and validation records

`pre-python-only-launcher/` preserves the launcher, tests, figure inventory and
validation records that were present on `main` at commit
`ee35cfd5f440f4e02450aad47fe1534fb7854a8d`.

These files document earlier releases; they are not the active launcher and
their successful-run statements do not certify the current Python-only
release. Use the repository-root README, `One_click.ipynb`, `launcher.py` and
the current release's verification record instead.

Previous Git tags, published release assets, scientific data, and the separate
calibration and artwork audit records are retained. Historical wording is kept
as provenance rather than silently rewritten.
